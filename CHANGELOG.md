# Jeevya 1.1.0

Release date: 2026-09-21

## Highlights

- Introduced Jeevya Widget Studio for configurable Android home-screen widgets.
- Added modular widget blocks that can be selected, reordered, and saved per widget configuration.
- Added widget presets for Daily, Health, Finance, and Progress dashboards.
- Added configurable widget size, layout, density, background, and accent colour.
- Added independent configuration support for multiple Android widget instances.
- Added Jeevya widget deep-link and snapshot integration while preserving local-first data safety.
- Updated Expo SDK packages to the versions required by Expo Doctor.
- Added the Expo Router patch required by the current router release.
- Preserved existing authentication, sync, backup, analytics, nutrition, workout, and reliability checks.
